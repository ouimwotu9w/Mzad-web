# مزاد الكورة (Kora Mzad)

لعبة مزاد وتدريب كرة القدم الاستراتيجية مع بطاقات اللاعبين والقدرات التكتيكية الخارقة والمحاكاة المباشرة في الملعب، أعيد بناؤها بالكامل باستخدام **React 19 + TypeScript + Vite + Tailwind CSS v4**.

## المميزات الرئيسية
- **قاعدة بيانات ضخمة**: أكثر من 481 بطاقة لاعب تغطي أساطير اللعبة ونجوم العصر الحالي ببيانات رسمية وتصنيفات واقعية.
- **15 أسلوب لعب فريد (PlayStyles)**:
  - ⚡ **عين حورس الأسطورية (Horus Eye)**: تسديدات ليزرية ودقة خيالية للمهاجمين وصناع اللعب.
  - 🐙 **الأخطبوط الأسود (Black Octopus)**: تصديات إعجازية وتمدد أسطوري لحراس المرمى والمدافعين.
  - 🎯 **القناص، الهدّاف الفتاك، الصقر الهوائي، الصاروخ النفاث، الرسام، المايسترو، الجدار الفولاذي، القفاز الذهبي، وغيرها**.
- **9 أوضاع لعب استراتيجية**:
  - خماسي مفتوح (Five Open)
  - خماسي سري (Five Secret)
  - المحترفين 11 ضد 11 مفتوح (Pro Open)
  - المحترفين 11 ضد 11 سري (Pro Secret)
  - المزاد الخاطف (Lightning Auction)
  - درافت المدربين (Manager Draft بنظام Snake Pick)
  - فريق الأحلام (Dream Team)
  - المزاد الأعمى (Blind Auction)
  - ليلة عين حورس (Horus Night بفرص أسطورية مضاعفة 5x)
- **نظام تعويض التشكيلات (Consolation Starters)**: يمنح الفرق المتعثرة بطاقات متوازنة لإكمال الخطة قبل المباريات.
- **محاكاة تكتيكية مباشرة 2D**:
  - رسم مباشر لملعب كرة القدم على عنصر Canvas بحركات للاعبين ومسار الكرة.
  - مؤثرات بصرية خاصة للقدرات الأسطورية (شعاع عين حورس، أذرع الأخطبوط).
  - شريط تعليق كروي باللهجة المصرية الحماسية.
  - حسم ركلات الترجيح (Penalty Shootout) واختيار رجل المباراة (MVP).
- **حفظ تلقائي للتقدم**: عبر `localStorage` للاستئناف في أي وقت.

## البناء والتشغيل
```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء للإنتاج
npm run build
```
